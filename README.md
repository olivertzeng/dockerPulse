# dockerPulse
Portainer but lighter. Provides a web interface to monitor docker container status remotely.

Well, technically the awesome https://github.com/louislam/dockge exists but this is for the sake of me learning to learn stuff while not reinventing the wheel

I also would like to achieve stuff that dockge does not do in my project in the future, such as solving permission issues, backing up databases and more.
